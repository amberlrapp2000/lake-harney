# Lake Harney water-level analysis

Interactive public-sharing copy prepared November 23, 2026. Open index.html to explore six tabs. This is a fixed research snapshot; data do not update automatically. Personal attribution has been removed. Sources and limits remain in the page. Correlations do not establish causation; neighborhood drainage connections remain unverified.

## Publish with GitHub Pages

1. Create a public repository named lake-harney using a free GitHub account.
2. Upload index.html and .nojekyll to the repository root and commit them to main.
3. Open Settings → Pages. Under Build and deployment choose Deploy from a branch, main, / (root), then Save.
4. Wait for deployment to finish and use the Visit site link supplied by GitHub. No custom domain is required.

The expected address format is https://YOUR-USERNAME.github.io/lake-harney/ (a template, not an already published URL). Visitors do not need an account. The repository files will be public. Update index.html on the same branch to update the page while keeping its URL.
